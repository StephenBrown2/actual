`TransactionsTable` (debit/credit input cells, running balance, drag preview, split error footer) and the underlying `serializeTransaction`/`deserializeTransaction` helpers now operate at the active currency's decimal places, with a unit test covering 0/2/3 decimal round-trips. Adds `formatCurrencyInput` to the shared util to keep in-cell formatting decimal-aware regardless of the user's `hideFraction` preference. The Currency settings dropdown lists `KWD`.
